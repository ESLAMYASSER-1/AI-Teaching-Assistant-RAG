# AI Teaching Assistant RAG

This repository contains the backend for an AI Teaching Assistant built on a Retrieval-Augmented Generation (RAG) architecture. It allows users to upload documents, process them into a searchable knowledge base, and ask questions to receive context-aware answers generated by a Large Language Model (LLM).

The application is built with FastAPI and features a modular design that allows for different LLM providers (for embeddings and generation) and vector databases to be plugged in.

## Architecture

The system follows a standard RAG pipeline:

1.  **Data Ingestion**: Users upload documents (e.g., PDF, TXT) to a specific project via a REST API.
2.  **Processing & Chunking**: The uploaded documents are processed and split into smaller, manageable chunks. The files and their corresponding chunks are tracked in a MongoDB database.
3.  **Indexing**: Each chunk is converted into a vector embedding using a selected embedding model (e.g., OpenAI, Cohere, Sentence-Transformers). These embeddings are then stored and indexed in a Qdrant vector database for efficient semantic search.
4.  **Retrieval & Generation**: When a user asks a question:
    *   The question is converted into a vector embedding.
    *   The vector database is queried to find the most relevant document chunks (the "context").
    *   The context and the original question are passed to a generative LLM (e.g., OpenAI, Cohere) using a structured prompt.
    *   The LLM generates a final answer based on the provided information.

## Features

*   **Project-Based Data Management**: Organize documents and knowledge bases into separate projects.
*   **File Upload**: Supports `.txt` and `.pdf` file types.
*   **Pluggable Backends**: Easily switch between different services for core functionalities.
    *   **LLM Providers**: OpenAI, Cohere, and local Sentence-Transformers (`IntFloat`).
    *   **Vector Database**: Qdrant.
*   **RESTful API**: A comprehensive API for uploading, processing, and querying data.
*   **Multi-language Support**: Prompt templates are available in English and Arabic.
*   **Containerized Dependencies**: Comes with a Docker Compose configuration for easy setup of MongoDB.

## Tech Stack

*   **Backend**: Python 3.8+, FastAPI
*   **Database**: MongoDB (for metadata), Qdrant (for vector storage)
*   **NLP/LLM Libraries**: LangChain, OpenAI Python SDK, Cohere, Sentence-Transformers
*   **Containerization**: Docker, Docker Compose

## Getting Started

Follow these instructions to get the application running on your local machine.

### Prerequisites

*   Python 3.8 or later
*   Docker and Docker Compose

### 1. Clone the Repository

```bash
git clone https://github.com/eslamyasser-1/ai-teaching-assistant-rag.git
cd ai-teaching-assistant-rag
```

### 2. Start Database Services with Docker

The project uses MongoDB for storing metadata. A Docker Compose file is provided for convenience.

```bash
# Navigate to the docker directory
cd docker

# Create a .env file from the example
cp .env.example .env

# Add your MongoDB credentials to the .env file
# MONGO_INITDB_ROOT_USERNAME=your_user
# MONGO_INITDB_ROOT_PASSWORD=your_password

# Start the MongoDB container in the background
sudo docker compose up -d

# Return to the root directory
cd ..
```
This will start a MongoDB instance accessible at `localhost:27007`.

### 3. Set Up the Python Application

```bash
# Navigate to the source directory
cd src

# Create and activate a Python virtual environment
python3 -m venv venv
source venv/bin/activate

# Install the required packages
pip install -r requirements.txt

# Create a .env file from the example
cp .env.example .env
```

### 4. Configure the Application

Open `src/.env` and fill in the required values. **You must update the `MONGODB_URL` with the credentials you set in the `docker/.env` file.**

```env
# Example src/.env configuration
APP_NAME="AI-Teaching-Assistant-RAG"
APP_VERSION="0.1"

# --- File Upload Settings ---
FILE_ALLOWED_TYPES=["text/plain", "application/pdf"]
FILE_MAX_SIZE=10 # in MB
FILE_DEFAULT_CHUNK_SIZE=512000 # 512KB

# --- MongoDB ---
# Use the credentials from docker/.env
MONGODB_URL="mongodb://your_user:your_password@localhost:27007"
MONGODB_DATABASE="pasos-rag"

# --- LLM Config ---
# Choose your backends: OPENAI, COHERE, IntFloat (for embedding)
GENERATION_BACKEND=OPENAI
EMBEDDING_BACKEND=OPENAI

# API Keys
OPENAI_API_KEY="sk-..."
COHERE_API_KEY=""

# Model IDs
GENERATION_MODEL_ID="gpt-3.5-turbo"
EMBEDDING_MODEL_ID="text-embedding-3-small"
EMBEDDING_MODEL_SIZE=1536 # For text-embedding-3-small

# --- Vector DB Config ---
VECTOR_DB_BACKEND=QDRANT
VECTOR_DB_PATH="qdrant_db"
VECTOR_DB_DISTANCE_METHOD="cosine"

# --- Template Configs ---
PRIMARY_LANG="en"
DEFAULT_LANG="en"
```

### 5. Run the FastAPI Server

From the `src` directory:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 5000
```

The API will be available at `http://localhost:5000`.

## API Endpoints

The API is organized by projects, identified by a `project_id`. A Postman collection is available at `src/assets/passos-app.postman_collection.json`.

| Method | Endpoint                             | Description                                                                 |
| :----- | :----------------------------------- | :-------------------------------------------------------------------------- |
| `GET`  | `/api/v1/`                           | Welcome endpoint. Returns the app name and version.                         |
| `POST` | `/api/v1/data/upload/{project_id}`   | Upload a file (`.txt`, `.pdf`) to a specific project.                       |
| `POST` | `/api/v1/data/process/{project_id}`  | Chunks the uploaded documents for a project and saves them to MongoDB.      |
| `POST` | `/api/v1/nlp/index/push/{project_id}`| Generates embeddings for chunks and pushes them to the vector DB (Qdrant).  |
| `GET`  | `/api/v1/nlp/index/info/{project_id}`| Retrieves information and stats about a project's vector collection.        |
| `POST` | `/api/v1/nlp/index/search/{project_id}`| Performs a semantic search for similar documents in the vector index.     |
| `POST` | `/api/v1/nlp/index/answer/{project_id}`| Asks a question and receives a RAG-generated answer.                        |

## Basic Workflow

1.  **Upload a Document**: Create a new project by uploading your first document.
    `POST /api/v1/data/upload/my_first_project` (with a file attached)

2.  **Process the Document**: Chunk the document into smaller pieces.
    `POST /api/v1/data/process/my_first_project`

3.  **Index the Content**: Create vector embeddings and push them to the knowledge base.
    `POST /api/v1/nlp/index/push/my_first_project`

4.  **Ask a Question**: Get a context-aware answer from your document.
    `POST /api/v1/nlp/index/answer/my_first_project` (with a JSON body like `{"text": "your question here"}`)
